# 卫戍协议更新

[下载最新累计更新包](https://github.com/zdzebhz/weishu-protocol-releases/releases/latest)

此仓库提供正式更新包和版本记录。需要已有游戏安装，不是完整客户端。

1. 关闭游戏和启动/P2P 窗口，下载 Release 中的 `weishu-update-*.zip`。
2. 把 ZIP 内容完整解压到实际游戏根目录，运行 `Update-Game.cmd`，等待“结果：OK”。
3. 以后使用 `Launch-Game.cmd` 启动。联网检查更新请单独运行 `Check-Updates.cmd`，显示版本后自行确认安装。

已验证的早期多人包、R3/1.2、其 1.3 更新、正式 1.4 及受管理修订使用同一个入口。
工具根据原安装清单识别，需要时先迁移旧资源，再更新程序，无需选择定制包。
未知基线或校验失败会停止并显示原因；缺少旧资源时需要该安装对应的原始完整 ZIP。
正常启动不联网检查更新，不需要 GitHub 账号或令牌。下载失败不会报告更新成功。

保留存档、配置、房间、队伍、活动时钟和原始安装身份。历史文件仅按已确认内容清理，修改过的说明保留。
房主和所有队友都要更新到相同修订，然后重新生成连接码。

请下载 Releases 附件中的更新 ZIP；GitHub 自动生成的 Source code 压缩包仅包含此仓库的发布记录，不能更新游戏。
每次发行使用唯一修订和 SHA256，不覆盖已经发布的版本。

`v1.4-20261027.3` 发布后已通过匿名下载、实际安装和再次检查。[公开下载验证记录](releases/v1.4-20261027.3/network-verification.json)
